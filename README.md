# TOEIC 學習網站

一個**純前端**的多益（TOEIC）自學網站，部署於 GitHub Pages。黑底螢光綠的終端機風格，把「背單字、練發音、學文法、做測驗」整合在一個免安裝的網頁裡，三個分頁：**單字**、**發音**、**文法**。



---

## 功能介紹

### 📘 單字
- **單字卡**：英文單字 ＋ KK 音標，第二行附「音節拆解」，再加中文、詞性與記憶筆記。
- **真人發音**：🇬🇧 英式 / 🇺🇸 美式（Google 真人音質）；🔁 重複與循環播放。可用**速度拖曳桿**（0.1x–2.0x）即時調整語速。
- **自我測驗**：可遮住英文或中文考自己；每次載入單字順序隨機洗牌。
- **抽考測驗**：自選範圍與題型（看英文選中文／看中文選英文），四選一、即時對錯回饋、正確／錯誤清單分列，答錯的字自動收進「答錯簿」方便複習。

### 🗣️ 發音
- **KK 音標一覽表**（母音／子音），每個音附英文例字與 🔊 發音示範。
- KK 音標以**劍橋美式**為準，和單字卡的美式發音一致。

### 📖 文法
- **7 大類、41 個主題**，從最基礎的「主詞、動詞、詞性、be 動詞」到各種時態、句型。
- 點入為**全螢幕教學**：公式結構、變化規則、使用時機、常見錯誤、例句重點上色與自繪時間軸圖，讀完附「小試身手」。

---

以自學者為對象，不需登入、不需安裝，打開網頁就能用。

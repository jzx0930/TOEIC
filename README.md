# TOEIC 單字卡 📘

一個純前端的多益（TOEIC）英語單字學習網站。以「單字卡」形式呈現單字、KK 音標、中文翻譯與記憶筆記，並內建**真人發音**、**循環朗讀**與**隨機抽考測驗**，幫助背單字與練聽力。

介面為繁體中文，視覺採黑底配螢光綠的終端機風格。整站為靜態網頁，可直接部署於 GitHub Pages。

---

## ✨ 功能特色

- **單字卡學習**：每張卡顯示英文、KK 音標、詞性、中文翻譯，以及記憶筆記（如音節拆解法）。
- **遮字自測**：可單獨或整批隱藏／顯示英文與中文，方便遮住答案後自我測驗。
- **真人發音**：透過 Google Text-to-Speech 提供英式 🇬🇧 / 美式 🇺🇸 發音；另有「循環重複朗讀」單字（使用瀏覽器內建語音）。
- **循環朗讀區塊**：一鍵依序朗讀整個區塊的單字，朗讀中的卡片會自動置中並高亮，並出現一顆跟隨的「停止循環」直書按鈕。
- **隨機抽考測驗**：可**複選多個**測驗範圍（或選「全部範圍」）並選題型（中選英 / 英選中），系統會把所有勾選範圍的單字合併出題，即時記錄正確 / 錯誤清單與分數。
- **搜尋**：跨所有區塊搜尋單字，命中後自動展開區塊、捲動並標亮。
- **筆記**：有筆記的單字可單獨或整批展開 / 收合。
- **響應式設計**：桌機、平板、手機皆可使用（1200 / 768 / 480 三個斷點）。

## 🚀 線上部署（GitHub Pages）

本專案為純靜態網站，部署步驟：

1. 將整個專案推送到 GitHub repository。
2. 進入 repo 的 **Settings → Pages**。
3. **Source** 選擇 `Deploy from a branch`，分支選 `main`（資料夾選 `/root`）。
4. 等待數十秒後，即可由 Pages 提供的網址開啟使用。

> 部署注意事項
> - 全站為純前端、使用相對路徑，無需任何後端伺服器。
> - GitHub Pages 在 Linux 上**區分檔名大小寫**，請確保 `fetch` 的檔名與實際檔名完全一致。
> - 外部資源走 HTTPS，符合 Pages 的安全頁面需求。

## 📝 單字資料格式

頁面載入時會先讀取 `word/list.json`，再依序載入清單中的每個檔案，每個檔案會成為一個可折疊的章節區塊（區塊名稱＝檔名去掉副檔名）。

### 1. 索引檔 `word/list.json`

一個字串陣列，列出要載入的檔名與順序：

```json
[
  "聽力單字1.json",
  "Word UP1.json",
  "單字1.txt"
]
```

### 2. JSON 格式（建議）

物件陣列，每個物件代表一個單字：

```json
[
  {
    "word": "colleague",
    "kk": "[ˈkɑlig]",
    "translation": "同事",
    "part_of_speech": "n.",
    "note": "可在此寫記憶法、例句等筆記（可留空）"
  }
]
```

| 欄位 | 說明 | 必填 |
| --- | --- | --- |
| `word` | 英文單字 | ✅ |
| `translation` | 中文翻譯 | ✅ |
| `kk` | KK 音標 | 選填 |
| `part_of_speech` | 詞性 | 選填 |
| `note` | 記憶筆記（有填才會出現 📝 按鈕） | 選填 |

### 3. TXT 格式（舊版相容）

每行一個單字，用 `|` 分隔英文與中文：

```
colleague|同事
competitor|競爭者、對手
```

### 新增單字的步驟

1. 在 `word/` 內新增一個 `.json`（或 `.txt`）檔。
2. 把該檔名加進 `word/list.json`。
3. 重新整理頁面即可看到新區塊（測驗範圍下拉選單也會自動加入）。

## 🔊 發音說明

- **單次發音（🇬🇧 / 🇺🇸）**：呼叫 Google Text-to-Speech API，音質較佳。
- **循環重複（🔁）與循環朗讀區塊**：使用瀏覽器內建的 `SpeechSynthesis`，不耗用 API 額度。

> ⚠️ **API 金鑰安全提醒**
> `index.html` 內目前直接寫入了 Google API 金鑰。金鑰寫在前端原始碼會被任何人看到，公開部署前**強烈建議**改用「HTTP 來源（Referrer）限制」鎖定你的網域，或改走後端代理，以免被盜用而產生費用。

## 💻 本機執行

由於頁面會用 `fetch` 讀取本地 JSON 檔，**不能直接用 `file://` 開啟**（會被瀏覽器的 CORS 政策擋下），請用一個簡單的本機伺服器：

```bash
# 任選一種（在專案根目錄執行）
python -m http.server 8000
# 或
npx serve
```

接著瀏覽器開啟 `http://localhost:8000`。

## 🎯 抽考測驗（複選範圍）

測驗範圍採**核取方塊複選**，可同時挑選多個單字區塊一起出題。

- 預設勾選「全部範圍」；每個載入的單字檔都會成為一個可勾選的範圍選項。
- **互斥規則**：勾「全部範圍」會自動取消其他特定範圍；勾任一特定範圍會自動取消「全部範圍」；若把特定範圍全部取消，會自動勾回「全部範圍」，避免一個都沒選。
- 按「開始抽考」時，系統會把**所有被勾選範圍**的單字合併成題庫（勾「全部範圍」或都沒勾即使用全部）。
- 合併後若單字量不足 4 個（無法湊出 1 正解 + 3 干擾項），會提示無法開始。

選好題型（中選英 / 英選中）後即可作答；作答時會即時統計正確 / 錯誤，並把答對、答錯的單字分別列在左右兩側清單。

## 💾 錯誤單字儲存（錯題本）

測驗時答錯的單字可以在測驗結束後，存進 `word/Unfamiliar.json`（「不熟」單字檔），方便日後複習。

### 原理

瀏覽器（無論本機或 GitHub Pages）基於安全沙箱，**無法自動、靜默地改寫你電腦或 repo 裡的檔案**。本功能因此採用兩種機制，依瀏覽器能力自動選擇：

- **File System Access API（Chrome / Edge）**：使用者主動選定一個本機 JSON 檔並授權後，網頁就能讀取與寫回該檔。這需要「使用者點擊手勢」才能觸發（所以是用按鈕讓你再點一次，而不是自動存）。同一次開啟頁面內會記住該檔案 handle，不必每次重選。
- **下載備援（Firefox / Safari 等不支援的瀏覽器）**：自動改為下載一個 JSON 檔，內容是本次新增的單字，需自行併入 `word/Unfamiliar.json`。

> 重要：此功能寫入的是「使用者本機選定的檔案」。部署在 GitHub Pages 上時，它**不會也無法自動 commit 回 repo**。若要讓錯題進到線上版，流程是：本機（用 Chrome/Edge）存進 `Unfamiliar.json` → 你再 `git commit` / `push`。

### 流程

1. **觸發時機**：測驗全部作答完畢（結算畫面），或按「提前結束測驗」並確認離開後。只要本次有答錯的單字，畫面就會出現「💾 儲存錯誤單字（N）到 Unfamiliar.json」按鈕。
2. **點擊儲存**：
   - Chrome / Edge：跳出檔案選擇 → 你選定本機的 `word/Unfamiliar.json` 並授權讀寫。
   - 其他瀏覽器：自動改為下載 JSON 檔。
3. **去重附加**：程式讀取該檔現有內容，以「單字（小寫）」比對，**已存在的字自動略過**，只把新的錯字加進去。
4. **寫回檔案**：將更新後的陣列以 2 空格縮排寫回 `Unfamiliar.json`，並提示實際新增了幾個單字。

### 資料格式

存入的每個單字物件與 `word/*.json` 完全相同（音標、詞性、筆記先留空，可日後自行補上）：

```json
{ "word": "colleague", "kk": "", "translation": "同事", "part_of_speech": "", "note": "" }
```

> 注意：每次測驗只會匯出**該次**答錯的單字（同一次測驗內同一個字只計一次）。

## 🔄 改版後的快取處理

`index.html` 載入樣式與腳本時帶有版本參數，例如：

```html
<link rel="stylesheet" href="index.css?v=4">
<script defer src="index.js?v=4"></script>
```

每次修改 `index.css` 或 `index.js` 後，把 `v=4` 的數字往上加（`v=5`、`v=6`…），即可強迫瀏覽器（含 GitHub Pages）重新抓取最新檔案，避免使用者看到舊的樣式或程式。
